# Zero-cost architecture
GitHub repository privato, Cloudflare Workers Free, Cloudflare D1 Free e Telegram Bot API.
Nessun GitHub Actions pianificato nel repository privato, nessun VPS, proxy, scraping a pagamento o API LLM a consumo.
Con le quote Free, superare i limiti può interrompere l'operatività: non attivare piani a pagamento.
La registrazione di un negozio non ne implica il monitoraggio. Amazon Creator API non va considerata gratuitamente disponibile senza verifica ammissibilità.
Attivazione ancora necessaria: account Cloudflare Free, D1 database id, Telegram bot token/chat id/webhook secret inseriti in Worker Secrets. NON pubblicare segreti.
